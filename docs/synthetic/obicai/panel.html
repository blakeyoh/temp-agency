The panel

Twelve people are named in the source research; the ten with actual biographies are simulated here. Alyssa Gross and David Khan appear only as names in an org chart, so there was nothing to build a respondent from. This is the first panel with real frontline depth — five of the ten run a dining room or a kitchen, hold end-user authority, and hold no budget authority at all. Each person drew a different persona, so no two respondents reason the same way.
