# Phase 5 contract review: host findings and pending decisions

This partial Phase 7 review covers E3, E4 and E5 only. It is not the full independent
contract read or readiness authorization. GLM reviewed the manifested code and contracts;
the host reviewed the findings, fixes and tests. The model did not execute tests.

## Confirmed gaps

- **E3:** The complete-roster lexical router works, but Amendment 5 requires per-item
  frame dependence and regeneration, plus preservation of the wrong expert's answer
  structure through synthesis. Its binding deliberately fails until that gate exists.
  Extending the E2 independent-evaluator pattern is proposed, not presumed approved.
- **E4:** The tool implements the plan's explicit crossover-only scope. The frozen
  evidence contract additionally requires point mutation, scoring, selection and retained
  promotion/death history. A passing crossover receipt does not establish that lifecycle.
  The commissioner must choose completing the original mechanism or recording a narrower
  amendment; neither choice has been silently written into the governing contract.
- **E5:** The frozen 1911 wordlist and regeneration chain work. The finite list does not
  detect every modern concept expressed with period diction. Independent concept review
  is proposed as additional enforcement. The single supported setting and conservative
  rejection of historical uses of “network” are disclosed. No exhaustive historical
  dictionary or historical existence of each modern role is claimed.

## Implementation finding resolved

The review identified prefix-substring matching of E3's LEAD/LENS labels. The host
replaced it with exactly one matching whole line per label. New tests reject suffix
spoofing, duplicate labels and a “NOT LEAD” phrase. All nine route tests pass.

The model called E3's intentional failed deletion check an implementation defect. The
host distinguishes an unfinished enforcer from a defective router: keeping this check
false is required until real frame verification exists. The model's suggestion that
E5 can proceed under its narrower scope is a proposed contract amendment, not approval.

## Commissioner decisions (2026-09-13)

The commissioner resolved the three scope questions without changing the historical
review above:

- **E3:** Add a small independent evaluator analogous to E2 for the frame-dependence
  check. Implementation is underway; E3 is not ready for enactment or dispatch. The
  tournament may reject a weak mechanism rather than expanding this gate beyond its
  purpose.
- **E4:** Adopt the explicitly intended crossover-only scope for this stage: two distinct
  parents, a seed, and a literal child. Point mutation, scoring, selection, and
  promotion/death history are not mandatory at this stage.
- **E5:** Keep the existing instruction plus frozen 1911 wordlist. Add no independent
  concept-review step. The limitation that hidden modern concepts can evade the surface
  list remains disclosed.

These decisions do not authorize dispatch and do not determine Rulings 24/25.
