## MATCHUP 1
WINNER: A
DECIDED BY: A relocates the whole derivation to a foreign domain while B only scrambles the judgment inside the correct one — and A does it with a dispatch rule that costs nothing to maintain, while B costs 24 generated files that rot against the profiles they were degraded from.

### Distance
VERDICT: A significantly better
REFERENCE: A between Mid and High — it goes past the left-fielder reference because the wrong domain holds authority, not just a seat. B between Low and Mid — the domain never changes, so the understudy's output orbits the correct answer at a fixed radius.
PREDICATE: A forbids the migration answer whose spine is "Phase 1 schema audit → dual-write → backfill → cutover"; the referee must instead produce a spine of advantage, materiality, restart, and escalating sanction. B forbids the systems-thinker output that opens "first, let's bound the system" — the understudy must rank leverage points before it has mapped anything. Both nameable, but B's forbidden output is forbidden relative to the persona, not relative to the median model answer, which is what this axis measures.

### Mechanism
VERDICT: Tie
REFERENCE: Both at Low (a structured prompt template with required sections). Neither reaches Mid — no self-verification checklist, no gate, nothing that rejects.
PREDICATE: For A there is no file that runs; the change is a selection rule in SKILL.md that the model reads and applies to itself. For B there is also no file that executes — roster/understudy/[slug].md would be a generated prompt, and a second agent pass is still a prompt, not machinery. B has more artifacts; artifacts are not execution.

### Irreducibility
VERDICT: B slightly better
REFERENCE: Both at Low (hand the model a persona file — real, but promptable). Neither reaches Mid; nothing rejects, nothing is withheld.
PREDICATE: A base model prompted "answer this database migration as a soccer referee would, deriving everything from refereeing primitives" reproduces ~70% of A. Prompted "roleplay a student of this expert who has the method but not the judgment — misapply the phases, over-use the signature move, misidentify the load-bearing principle" reproduces ~55% of B; the gap is that the model's reflex is a labeled safe mistake, and holding four degradation axes simultaneously is what the file buys.

### Compounding
VERDICT: A slightly better
REFERENCE: A at Low (a novelty effect that fades). B at Floor — the understudy of a given persona is a fixed distortion, so repeated use of the same pairing is literally the same misapplication.
PREDICATE: A's use #10 produces a tenth costume and nothing more; worse, a reader who has seen nine has learned to skim the referee vocabulary and read the lens paragraph, so use #10 produces less effect than use #1. B's use #10 produces the identical phase inversion and the identical over-used move — plus, by then, an understudy file derived from a parent profile edited three times since, so the drift produces error rather than novelty. Neither has a stock that grows; A at least has 552 lead/lens pairings before it visibly repeats, and no artifact to keep alive across seasons.

### Generative failure
VERDICT: B significantly better
REFERENCE: A between Floor and Mid, and the Floor mode dominates. B between Mid and High.
PREDICATE: A's exact failure output: "Like a referee applying the advantage rule, you should let the broken writes play on and only stop the match when the damage is material" — followed by a technically correct, entirely conventional dual-write migration plan supplied by the domain-expert lens. The default answer arrives wearing a costume, at the position of maximum authority, and nothing flags it. B's exact failure output: an understudy that ranks leverage points for a system whose boundary was never drawn, producing "the highest-leverage move is to change the goal" applied to something outside the system — which names the hidden assumption that nobody had agreed what was inside it. B's failure is discardable and occasionally diagnostic; A's failure is undetectable and shippable.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: A systematically degraded copy whose misapplications carry internal logic, so its errors can be read as proposals instead of discarded.
SAME-THESIS: FAIL — A's claim is that the wrong domain at maximum authority defeats domain-appropriate matching; degradation is a claim about wrong judgment inside the right domain. A's referee has full judgment and the wrong primitives; the understudy has the right primitives and broken judgment. That is a second claim.
DELETION: FAIL — merely smaller. Delete the understudy and A still staffs the least relevant specialist as lead, still forces derivation from foreign primitives. Nothing in A depends on it.
ONE-SENTENCE: FAIL — the "and also" cannot be removed; the two mechanisms attack the same reflex from unrelated directions and share no machinery.
DISPOSITION: ORTHOGONAL
NOTE: Two independent defeats of domain-appropriate matching that happen to be in the same bracket; merging them yields two mechanisms in one repo, not one idea, and doubles the maintenance ledger that already decided the matchup.

## MATCHUP 2
WINNER: B
DECIDED BY: B is the only idea here whose constraint tightens as its own corpus grows, while A's grammar is identical on use #10 and sits under continuous pressure to loosen every time it wrongly rejects a good output.

### Distance
VERDICT: B slightly better
REFERENCE: A between Low and Mid — a grammar constrains form; the enforced structure is a formalized version of the Floor reference, rescued only because unsourceable claims must actually be dropped. B between Mid and High — it forbids a region rather than a shape, which is what this axis measures, but the steering is advisory, which keeps it off High.
PREDICATE: A forbids "sources say the migration was rushed" as an unparented claim node — narrow but genuinely enforced. B forbids an output landing in the corpus's densest cluster — if 40% of prior outputs cluster on "name the archetype, locate the leverage point, propose structural change," a void-steered dispatch may not land there. B's forbidding is wider and aimed at conventionality itself; A's is aimed at sloppiness, which is a different vice.

### Mechanism
VERDICT: A significantly better
REFERENCE: A at Ceiling — "a gate that rejects the output and forces regeneration without the model's consent" is a literal description of a PEG parser rejecting an unparseable output. B at High — a script runs and the model must consume its output, but nothing rejects.
PREDICATE: A's files that run: grammars/investigative-journalist.peg, grammars/nuclear-reactor-operator.peg, and a bin/parse-persona-output validator in the generation loop; parse failure is mechanically decidable. B's: a bin/idea-map embed-and-cluster script emitting docs/coverage-map.md; it executes and produces real output, but the consequence of ignoring it is nothing at all. This is A's only decisive axis and it is the axis on which the winner is weakest.

### Irreducibility
VERDICT: B slightly better
REFERENCE: A at Mid. B between Mid and High — the informational inverse of the High reference: rather than withholding a fact, it supplies one the model provably cannot compute, namely the empirical distribution of its own prior outputs.
PREDICATE: A base model prompted "here is the grammar; every claim must carry an explicit source or be labeled an unverified tip" reproduces ~65% of A's structure and 0% of its guarantee — the whole irreducible content of A is the rejection, not the form. Prompted "list directions this repo has never once pointed" reproduces ~15% of B, and that 15% is unverifiable guesswork: the model will name plausible-sounding voids that are already occupied, and has no way to discover the error.

### Compounding
VERDICT: B significantly better
REFERENCE: A at Floor with an active erosion loop. B at High, short of Ceiling only because a human can decline to look at the map.
PREDICATE: A's use #10 produces the identical parse constraint as use #1; the only change is that the grammar has been loosened at least once to admit a valid output it wrongly rejected. That is the structural prediction, not a worry: every false rejection creates pressure toward permissiveness and no counter-pressure exists, so the grammars drift toward accepting everything — Drift to Low Performance, with 24 hand-maintained .peg files as the standing cost. B's use #10 produces a void list excluding the nine regions uses #1-9 filled; the tenth dispatch is forbidden from nine directions open at use #1. The corpus is a stock, the map is a function of the stock, and the constraint tightens because the stock grows. That is a reinforcing loop, and it is the only one in this bracket. The year-three bill is real — embeddings recomputed, cluster labels drift, remaining voids empty for cause — but that is a compounding mechanism degrading, not an absent one.

### Generative failure
VERDICT: B significantly better
REFERENCE: A between Floor and Low — either an error and a wasted run, or the worse mode: a certified default. B at High.
PREDICATE: A's exact failure output: ParseError on a claim node with no SOURCE child, repeated until the model discovers it can attach SOURCE: "the user's own message" or "internal reasoning" to every claim — at which point the output parses perfectly, says exactly what it would have said unsourced, and now carries a structural certificate that it is well-attributed. A gamed gate is worse than no gate because it certifies. B's exact failure output: the map reports "no output has ever landed near {liturgical time, actuarial pricing, coastal erosion}," a dispatch steered there produces an incoherent forced hybrid — and the incoherence names the hidden assumption, which is that the void exists because the dispatch rule (lead = domain match) makes that region structurally unreachable. The empty region turns out to be a map of the rule's blind spot rather than of unexplored good ideas.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: A gate that rejects an output and forces regeneration without the model's consent.
SAME-THESIS: PASS — B's single claim is that the repo's own output distribution should constrain the next output, and B's stated weakness is that "steered toward" is not "forbidden from." The gate does not add a claim; it makes B's existing claim binding. Note the precision required: what is absorbed is the rejection primitive, not the persona grammar — a BNF of epistemology would be a second claim and is refused.
DELETION: PASS — worse, not smaller. Delete the gate and B reverts to an advisory map: dispatches keep landing in dense clusters, the void list keeps reporting the same voids, the reinforcing loop never closes, and the map becomes a report nobody opens by month four. B's entire compounding advantage is conditional on outputs actually going where the map points.
ONE-SENTENCE: PASS — "Cluster every output the repo has ever produced and reject any new output that lands in a region the corpus has already filled."
DISPOSITION: ABSORBED
NOTE: This is the rare case where the loser supplies the enforcement the winner's own thesis was already reaching for, and the merged mechanism is cheaper to maintain than either parent — one distance threshold against a corpus that maintains itself, rather than 24 grammars maintained by hand.

## MATCHUP 3
WINNER: A
DECIDED BY: A's constraint tightens automatically against a corpus that grows with every use, while B's foraging is memoryless — object #10 is drawn from the same distribution as object #1 and nothing is ever excluded.

### Distance
VERDICT: B slightly better
REFERENCE: A between Low and Mid — it measures distance without directing it, so the model satisfies it by adding lexical variation rather than by relocating. B between Mid and High — it does not forbid the problem's vocabulary, but it forbids the answer's self-sufficiency, which is adjacent.
PREDICATE: A forbids a systems-thinker output whose cosine similarity to the unstaffed baseline exceeds threshold — forbids shipping "this is a Limits to Growth archetype; the leverage point is defect rate" when the no-persona baseline said the same thing in different words. B forbids any output that could have been written without the foraged object: if the harness draws the Wikipedia page on Doggerland, B forbids both the answer that never mentions Doggerland and the answer that mentions it only in the opening line. B relocates by injection; A penalizes by measurement, and penalties can be paid in vocabulary.

### Mechanism
VERDICT: A significantly better
REFERENCE: A at Ceiling — a CI check failing a pull request is exactly "a gate that rejects the output and forces regeneration without the model's consent." B between Mid and High: the fetch is a script whose output the model must consume (High), but the rejection criterion is a checklist the model self-verifies against (Mid).
PREDICATE: A's files that run: .github/workflows/novelty.yml plus bin/novelty-score, and the failing condition is mechanically decidable by a machine that has no opinion. B's file that runs: bin/forage, which genuinely fetches. But "the foraged object must be load-bearing" has no decidable test; the only available judge is a model, and a model asked whether a paragraph is load-bearing will say yes. B's gate is a gate in name.

### Irreducibility
VERDICT: B significantly better
REFERENCE: A between Low and Mid — the model can approximate its own baseline, so most of the effect is promptable; only the threshold and the prior-output corpus are not. B at High: the context window contains a concrete object the model could not have generated, which is the operative property of the High reference regardless of whether the fact is withheld or supplied.
PREDICATE: A base model prompted "write the answer you'd give with no persona, then rewrite it to be maximally different" reproduces ~50% of A. Prompted "bring in something unexpected from outside this domain and make it load-bearing" reproduces ~8% of B — and the 8% is retrieval from priors, which is precisely what B's own claim identifies as the failure. This is the cleanest irreducibility case in the packet and it is B's crown.

### Compounding
VERDICT: A significantly better
REFERENCE: A at High, missing Ceiling only because the threshold is a parameter a human can lower. B between Floor and Low — the novelty of a foraged object fades, and nothing accumulates underneath it.
PREDICATE: A's use #10 must clear lexical distinctness against nine prior outputs from the same persona rather than zero; the permitted region is strictly smaller than at use #1, and it shrinks without anyone deciding that it should. B's use #10 produces a tenth object drawn from the same distribution as the first, with no ledger and no exclusion of what has already been foraged — and a reader who has seen nine has learned to skim the foraged paragraph and find the real answer underneath. Honest year-three caveat on A: the threshold is a parameter, parameters are the weakest leverage point, and the first red check on a Friday afternoon gets answered by lowering it or adding the job to the allowed-to-fail list. But the corpus survives that erosion and keeps growing. B has nothing to erode because it has nothing accumulating. An irreducible one-shot is exactly the object this panel exists to catch.

### Generative failure
VERDICT: A slightly better
REFERENCE: A between Mid and High on its honest failure, with a named Floor mode. B between Low and Mid.
PREDICATE: A's exact failure output: a red check with inline annotations reading "this passage is 0.94 cosine to baseline" on four of six paragraphs — a diagnosis that the persona is decorative on this task, not just that the output is stale, and that is a proposal about which profile to fix. A's Floor mode, arriving by year two: an output that clears threshold because it uses "biotic," "fallow," and "second-order" while saying exactly what the baseline said — Goodhart, with a green check attached. B's exact failure output: "Like the Doggerland land bridge submerged by rising Holocene seas, your migration must account for gradual data drift," followed by the standard answer, with the foraged object doing no work past the analogy — cheap to discard, occasionally revealing which part of the problem has no analog, mostly noise. A's failure names something about the machinery; B's names something about the sentence.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: Inject one concrete external artifact the model could not have generated, and reject the pass if it is not load-bearing.
SAME-THESIS: FAIL — A's single claim is that nothing currently punishes a smoothed output and a red check does; that is a claim about incentives and measurement. Foraging claims the model's priors are the binding constraint, and supplies material rather than penalizing results. Two different diagnoses.
DELETION: FAIL — merely smaller. Delete foraging and A still computes novelty scores against a growing corpus, still fails pull requests, still annotates too-familiar passages. Every compounding property A won on survives the deletion untouched.
ONE-SENTENCE: FAIL — the clauses act at opposite ends of the pipeline; no sentence joins them without "and also."
DISPOSITION: ORTHOGONAL
NOTE: A pre-generation injection and a post-generation gate are complementary in a roadmap and unmergeable in an idea; stapling them together produces two mechanisms sharing a repo, each with its own maintenance bill.

## MATCHUP 4
WINNER: A
DECIDED BY: B's mechanism trains its own defeat — a persona told its first quartile dies learns to front-load disposable ideas, so by use #10 the destruction removes five deliberate throwaways and idea #6 is the same median answer the rule was built to kill.

### Distance
VERDICT: B significantly better
REFERENCE: A between Low and Mid — a tool-grounded answer is a more accurate answer, not a stranger one, and two personas running the same tool converge rather than diverge. B between Mid and High: the front-loaded answer is the median answer, and B deletes it by construction.
PREDICATE: A forbids "this repo's most-churned files are probably SKILL.md and the roster index" — any unmeasured claim about churn must be replaced by raw bin/churn output. That forbids speculation, which is a different vice from conventionality. B forbids, for "how should the roster grow," the outputs "add specialists in the domains users request most" and "run demand-driven /roster-add" — the first things generated are unavailable to synthesis, whatever they turn out to be. On use #1 this is the most direct attack on the median in the entire packet; the axis measures use #1, so B takes it, and the compounding axis is where that measurement is corrected.

### Mechanism
VERDICT: B slightly better
REFERENCE: A between High and Ceiling — real scripts run and their output must be consumed, and "no tool output, no pass" is grep-checkable. B at Ceiling: destruction unread, without consent, with nothing to negotiate.
PREDICATE: A's files that run: bin/churn, bin/seasons, bin/claims, bin/who-benefits, bin/units, bin/orders, plus git log --follow. B's: a harness wrapper — call it bin/bankrupt — that truncates the idea list before any synthesis agent reads it; twenty lines, no judgment required, cannot be gamed at the truncation step. B edges A because its gate needs nothing to keep working, while A's gate depends on every tool in the belt still running. Six tools cover three personas here; full roster coverage is thirty to fifty small programs, each coupled to a repo shape that changes. By year three a meaningful fraction of the belt is broken, and because "no tool output, no pass" blocks those personas entirely, the rule gets waived rather than the tools repaired. That compensating response should be priced in now.

### Irreducibility
VERDICT: A significantly better
REFERENCE: A at High — the tool output is a fact about the actual repo that does not exist anywhere in the model. B at Mid: the model cannot opt out of the truncation, but nothing is withheld and nothing outside the model is supplied.
PREDICATE: A base model prompted "which files in this repo have been touched most over two years, and what does commit cadence by month look like?" reproduces ~10% of A — it will guess, confidently and wrongly, and cannot check itself. Prompted "generate 20 ideas; I will delete the first 5 unread, so don't waste them" reproduces ~55% of B — it will perform the effect, writing five conspicuous throwaways and then trying harder, rather than undergoing it. A supplies information that does not exist in the weights; B rearranges the order in which the weights are read out.

### Compounding
VERDICT: A significantly better
REFERENCE: A between Mid and High — it accumulates material the persona must obey, and the tool reads a stock that grows. B at Floor, and below the floor in effect, because the mechanism actively trains the behavior it was built to prevent.
PREDICATE: A's use #10 runs bin/churn against a git history that now contains the files uses #1-9 created, so the tool measures the consequences of its own prior use — the farmer reading this year's soil sees last year's amendments in it. That is a genuine loop: outputs change the repo, the tool measures the repo, the measurement constrains the next output. B's use #10 destroys the same first quartile it destroyed at use #1, and because the destruction is unread by construction, nobody can learn anything from what was destroyed. Worse, the persona is told in advance, which is B's stated feature and is precisely the defeat mechanism: the announced quartile becomes a designated dumping ground, five deliberately weak ideas fill it, and idea #6 is the front-load the rule existed to delete. Fixes That Fail, with the compensating response arriving inside the first few uses rather than after a delay. The intervention converts from a filter into a ritual, and rituals are maintained long after they stop working.

### Generative failure
VERDICT: A significantly better
REFERENCE: A between Mid and High. B at Floor, aggravated by false certification.
PREDICATE: A's exact failure output: bin/churn returns "(no commits in range)" and a farmer required to cite it has nothing to cite — which produces the true and unwelcome finding that this ground has no seasons to read yet, and that everything said about the repo's history has been reasoning about a history it does not have. The mundane mode is a broken tool and a wasted run. B's exact failure output: an idea list whose surviving #6 reads "add specialists in the domains users request most" — the median answer, laundered through a destruction ritual and arriving stamped as non-obvious because the harness can attest that a quartile was destroyed. A failure that manufactures a certificate is the most expensive kind, because it removes the pressure that would otherwise find the problem.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: Destroy the front-loaded quartile unread, and tell the persona in advance so generation changes from the first token.
SAME-THESIS: FAIL — A's single claim is that models assert without measuring and a mandatory tool run replaces an assertion with an observation. Pre-announced destruction is a claim about generation order and incentives.
DELETION: FAIL — merely smaller. Delete bankruptcy and A still runs its tools, still requires the raw result, still forbids unmeasured claims, still reads a stock that grows.
ONE-SENTENCE: FAIL — the "and also" is load-bearing; the two act on different objects — one on the persona's evidence, one on its output queue.
DISPOSITION: ORTHOGONAL
NOTE: A already blunts front-loading by a different and more durable route — a persona whose first substantive token is a tool invocation cannot front-load a remembered answer, because it has not yet been allowed to speak one — so the absorption buys little even before the three tests refuse it.
