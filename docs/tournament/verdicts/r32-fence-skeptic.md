## MATCHUP 1
WINNER: A
DECIDED BY: A removes something — the domain expert's authority — while B removes nothing and adds a second, worse voice to a room that already has two.

### Distance
VERDICT: A significantly better
REFERENCE: A sits at Mid and slightly above it — the "named non-obvious domain" reference relocated to the lead position, so the non-obvious domain sets the frame rather than commenting on it. B sits at the Floor: the understudy runs alongside the real persona, so the median answer is still generated in full and the understudy is appended to it.
PREDICATE: A forbids the database-migration answer whose spine is "dual-write, backfill, verify, cut over in a low-traffic window" — the referee has no such primitive and must derive from advantage, restart, and consistent enforcement across two halves. B forbids nothing; every word of the ordinary output still ships with the understudy's stapled underneath. No nameable forbidden output → floor.

### Mechanism
VERDICT: Tie
REFERENCE: Both sit between Floor and Low. Each is a dispatch-time rule in prose that changes which markdown file loads into which slot; neither rejects anything.
PREDICATE: Neither has a file that runs. A is an edit to the selection paragraph in SKILL.md plus the load of an existing roster/[slug].md. B is at best a generated roster/understudy/[slug].md, itself markdown. Both score as exhortation with better routing.

### Irreducibility
VERDICT: B slightly better
REFERENCE: Both sit at Low — "hand the model a persona file," real but promptable. B is a half-step above because its degradation operators are four named transformations rather than a role name.
PREDICATE: A base model prompted "You are a soccer referee, derive an answer to this database migration from refereeing primitives only" reproduces ~85% of A. Prompted "You are the understudy: methodology but not judgment, apply phase 3 where phase 1 belongs" reproduces ~75% of B. Both inside the promptable band. Note the unverified claim at B's center: the degraded copy is produced by the same model that would otherwise make the "labeled, safe" mistake B says it prevents. That is a tip, not a finding.

### Compounding
VERDICT: Tie
REFERENCE: Both sit at Low — a novelty effect that fades as the pattern becomes house style.
PREDICATE: A on use #10 produces a different arbitrary mismatch; procedure, difficulty and permitted answer space are identical. B on use #10 runs degraded against a fresh question having learned nothing from nine prior error sets, because no error catalog is retained. Both answer "a different instance of the same thing."

### Generative failure
VERDICT: B slightly better
REFERENCE: A sits at Mid. B sits at High, with real risk of dropping below Floor.
PREDICATE: A fails as thin metaphor — "a migration needs a clear whistle, a visible signal before the change, the same standard in both halves" — never touching schema or rollback, discardable in one read. B fails as internally coherent misapplication: the understudy runs Phase 3 on a Phase 1 question and produces "who is compensated for this module continuing to exist?" — unusable, but it names a hidden assumption about maintainer incentive the correct sequence would never surface. Countervailing risk: B's failure is unlabeled and reads as competent, so the reader cannot tell understudy from expert. A mechanism whose failures are indistinguishable from its successes is a laundering risk.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: The four named degradation operators — methodology without judgment, wrong-phase application, over-used signature move, misidentified load-bearing principle.
SAME-THESIS: FAIL — A's claim is that domain-appropriate matching must be defeated at the position of authority. The operators carry a second claim: that systematic error has more internal logic than requested error. The wrong expert is not a degraded expert; it is an intact expert in the wrong room.
DELETION: FAIL — delete the operators and the referee still leads the migration and still derives from refereeing primitives. Merely smaller.
ONE-SENTENCE: FAIL — the first clause governs who holds authority, the second how well that holder executes; the merged rule needs both specified independently.
DISPOSITION: ORTHOGONAL
NOTE: Both defeat a different reflex — A defeats matching, B defeats competence — and combining them yields an unqualified expert executing badly, making the strangeness unattributable to either cause.

## MATCHUP 2
WINNER: B
DECIDED BY: B's input is the history of its own use, so run #500 differs from run #1; A's grammar is byte-identical on run #500 and enforces the shape of evidence rather than its existence.

### Distance
VERDICT: A slightly better
REFERENCE: A between Low and Mid — a sophisticated heading system for claim content, but LIMIT/INDICATION/STOP does force content the model would not volunteer. B also between Low and Mid: the map labels voids and dispatches are "steered," which is direction without prohibition.
PREDICATE: A forbids the journalist shipping "stakeholders here are likely misaligned" as a claim node with no SOURCE child — the parser, not the model, decides. B forbids nothing: "steered toward the voids" is advisory, and the proposal explicitly disclaims enforcement.

### Mechanism
VERDICT: A slightly better
REFERENCE: A at Ceiling — a gate that rejects and forces regeneration without consent. B at High — a script whose output the model must consume — stopping there, because consumption is voluntary.
PREDICATE: A: grammars/investigative-journalist.peg plus a validator invoked as a post-generation hook exiting nonzero on parse failure. B: an embedding-and-clustering job emitting a coverage rendering. Both real and runnable. A's additionally refuses.

### Irreducibility
VERDICT: B slightly better
REFERENCE: A sits exactly at Mid — the "parser that rejects it" reference verbatim. B between Mid and High: the mirror of "withhold a fact," injecting a fact the model cannot generate from inside — its own empirical output distribution with density.
PREDICATE: A base model prompted "every claim carries a source or is tagged TIP; every action states limit, indication, stop" reproduces ~70% of A; residual is drift enforcement past paragraph nine. Prompted "name five directions this repo has never explored" reproduces ~40% of B — it produces plausible gaps drawn from priors about what a persona repo typically lacks, precisely the distribution B exists to escape.

### Compounding
VERDICT: B significantly better
REFERENCE: A at Floor — identical on use #10. B at High, approaching Ceiling on tightening but failing "cannot be relaxed."
PREDICATE: A on use #10 conforms to the same fixed grammar; nothing about runs 1-9 constrains run 10. B on use #10 produces a map whose void set has been depleted by runs 1-9: the nine directions already taken are no longer void, so run #10 is steered somewhere run #1 could not have been. The narrowing is automatic and its input is the mechanism's own history.

### Generative failure
VERDICT: B significantly better
REFERENCE: A between Low and Mid, arguably below Mid because the discard is not cheap. B between High and Ceiling.
PREDICATE: A fails by producing a parse-conformant fabrication: unable to satisfy SOURCE, the journalist emits SOURCE: "internal analysis of the repository" on every claim and ships. The grammar validates the shape of a citation and cannot validate its existence, so the failure output is a fully-sourced-looking document whose sources are strings — worse than noise, and it damages the one persona whose entire epistemology is corroboration. B fails by rendering degenerate voids — "region 7: sparse; nearest terms: soil, liturgy, RAID" — useless as direction but naming a hidden assumption: that the repo's output space has coherent unexplored regions at all. A map whose every void is incoherent is itself a proposal: the repo is topically wide and stance-narrow.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: The parser gate that rejects non-conforming output and forces regeneration without the model's consent.
SAME-THESIS: FAIL — B's claim is informational: the model cannot see where it has been, so supply the map. A gate rejecting outputs in dense regions carries a second claim: that the option to be familiar must be removed. B's own text declines this. A rejection threshold also imports novelty-over-correctness, punishing the right answer for being the answer already given.
DELETION: FAIL — delete the gate and B is exactly what B was proposed as: a map. Merely smaller.
ONE-SENTENCE: PASS — the sentence is writable, but writing it converts B into a novelty gate, which is a different entry.
DISPOSITION: ORTHOGONAL
NOTE: One mechanism supplies information the model lacks, the other removes a choice the model has; a map that forbids is a fence, and a fence refuses the small repair in front of you because someone already repaired one like it.

## MATCHUP 3
WINNER: B
DECIDED BY: B injects material the model could not have sampled; A measures the model against itself with the model's own embedding, which is a mirror, not a window.

### Distance
VERDICT: B significantly better
REFERENCE: A between Low and Mid — it forbids proximity to default phrasing, but proximity is measured on embeddings, so the cheapest compliance is unusual vocabulary and the thought need not move. B at High arguing toward Ceiling.
PREDICATE: A forbids the baseline sentence "consider whether stakeholders are aligned and risks documented" but not that same judgment in rarer words — and rarer words are what the metric actually buys. B forbids any version of the review that could have been written before the draw: if the object is a two-year-old crontab, the review must be structurally dependent on it, and every review not so dependent is rejected regardless of how novel it reads.

### Mechanism
VERDICT: Tie
REFERENCE: Both High-to-Ceiling. Each names a gate; each has one component that is a judgment call rather than a computation.
PREDICATE: A: .github/workflows/novelty.yml plus a scorer setting check status. B: a pre-generation harness hook that draws and injects one artifact, plus a post-generation load-bearing check. A's soft point is a threshold on a fuzzy score; B's is who adjudicates "load-bearing." One accountability gap in A: nothing says who sets the threshold, and whoever sets it defines creativity for the repo.

### Irreducibility
VERDICT: B significantly better
REFERENCE: A at Mid — a rejecting check the model cannot opt out of, but whose yardstick is the model's own sense of its own default. B at High: the constructive form of "withhold a fact," injecting a token sequence the model could not have sampled.
PREDICATE: A base model prompted "estimate how close this is to what you would have said unstaffed, then rewrite until it is far" reproduces ~60% of A. Prompted "bring in something unexpected and make it load-bearing" reproduces ~15% of B: it reproduces the ritual and none of the content, because anything it brings in is drawn from the prior — the exact failure B was built to prevent. Largest irreducibility gap in the packet. Reduction test confirms: strip B to one random paragraph from the persona's own canon.md, one file read, no infrastructure, and nearly all the force survives. Strip A to "read your last three outputs and don't repeat yourself" and most of A's realized value survives at one percent of the cost — meaning most of A is machinery around a sentence.

### Compounding
VERDICT: A significantly better
REFERENCE: A at High touching Ceiling — lexical distinctness from all prior outputs shrinks the permitted space every run, automatically, until unsatisfiable. B at Low: the draw is independent each time.
PREDICATE: A on use #10 must avoid the vocabulary of nine prior outputs, measurably further from the persona's habitual register than use #1 could have been. It narrows vocabulary, not thought, and terminates in an unsatisfiable constraint someone quietly relaxes. B on use #10 is built on a tenth randomly drawn object; difficulty, procedure and permitted space are identical to use #1, and no archive of past draws constrains the next.

### Generative failure
VERDICT: A slightly better
REFERENCE: A at High on its informative failure, Low on its common one, netting to Mid. B at Mid.
PREDICATE: A fails most usefully by turning the check red on a correct output and annotating the persona's load-bearing principle as too-familiar — flagging "verify before releasing it" as a repeated passage. That names a hidden assumption exactly: no distance metric can separate a persona's signature principle from a tic, and the repo has no other way to tell them apart. A's more common failure is worse: the baseline is regenerated per run, the same diff scores differently twice, the check goes flaky, and a flaky red check is disabled within a month. B fails by strained analogy that passes its own gate — "like a .gitignore, your caching strategy is defined by what it refuses to track" threaded through four paragraphs, satisfying "load-bearing" while carrying no observation.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: A CI check that fails the build when output scores too close to an unstaffed baseline.
SAME-THESIS: FAIL — B's claim is about provenance: material genuinely from outside the prior. A threshold measures proximity, not origin. Merged, a properly foraged output landing near the baseline is rejected, and an unforaged output in exotic vocabulary passes. That inverts B's claim rather than serving it.
DELETION: FAIL — delete the CI check and B is intact: the artifact is still fetched, the pass still rejected when the object does no work. Merely smaller.
ONE-SENTENCE: FAIL — the second clause is a second gate with its own threshold, owner and regeneration loop, adjudicating a property the first does not measure.
DISPOSITION: ORTHOGONAL
NOTE: A measures output against the model's own distribution, B against something outside; running both means an output can be rejected for two unrelated reasons and the author cannot tell which failure to fix.

## MATCHUP 4
WINNER: A
DECIDED BY: B is a well-known prompt trick with a destroyed audit trail; A puts facts in the context window that the model cannot fabricate and a reader can check.

### Distance
VERDICT: B slightly better
REFERENCE: A between Floor and Low — it changes the evidentiary standard, not the shape; a data-grounded median answer is still the median answer. bin/seasons is the exception lifting it toward Mid. B between Low and Mid: it targets the median directly, but positionally rather than semantically.
PREDICATE: A forbids the farmer writing "this module has been churning for a while" with no bin/churn invocation and raw output beneath it. What it does not forbid is the ordinary conclusion, now decorated with real numbers. B forbids delivering "staff every task with two contrasting specialists" if it arrived as idea #2. The hole: destruction is positional and the claimed prohibition is semantic, and nothing connects the two. Idea #2 restated as idea #7 survives, and reordering is free.

### Mechanism
VERDICT: A significantly better
REFERENCE: A at Ceiling — multiple scripts whose output the model must consume, plus "no tool output, no pass," which is a refusal. B reaches Ceiling on the refusal criterion alone but has nothing whose output must be consumed.
PREDICATE: A: bin/churn, bin/seasons, bin/units, bin/orders, bin/claims, bin/who-benefits, git log --follow. A finding against A: bin/churn, bin/seasons, bin/units and bin/orders are computations over real data; bin/claims and bin/who-benefits almost certainly are not — "who benefits" is not derivable from a repository, so that binary is a model call in a shell script, a prompt wearing an executable's name. Four of six are real. B: none. B is a slice-and-discard step in the dispatch loop, three lines with no name. Scores as exhortation with a delete key.

### Irreducibility
VERDICT: A significantly better
REFERENCE: A between Mid and High — tool output is a fact in the context window the model could not have produced and cannot fake, because the raw result must be pasted and is checkable. B at Low, one notch above the floor: a specific, widely known prompt trick.
PREDICATE: A base model prompted "run git log --follow and bin/churn, paste raw output, then analyze" reproduces ~35% of A — it reproduces the framing and none of the numbers, and the numbers are the part that changes the answer. Prompted "generate 20 ideas; I will discard the first 5 unread" reproduces ~85% of B. B's load-bearing claim — that foreknowledge "changes what it generates from the first token" — is asserted and never corroborated. The cheapest compliance is to write five throwaways to burn the quota, collapsing B into "ask for twenty and read from six."

### Compounding
VERDICT: A slightly better
REFERENCE: A at Low touching Mid — accumulates material you may consult but need not obey. B at Floor.
PREDICATE: A on use #10 runs bin/seasons against a commit history that now includes nine intervening months, so the cadence bars differ and the observation differs; the tool is fixed but its input drifts. B on use #10 destroys the same first quartile against a fresh question with no memory of nine prior bankruptcies — N does not grow, nothing about runs 1-9 constrains run 10.

### Generative failure
VERDICT: A slightly better
REFERENCE: A at Mid, dragged toward Floor by its cheapest compliance path. B between Low and Mid, with an unauditability problem this panel treats as disqualifying independent of the axis.
PREDICATE: A fails as ceremonial evidence: bin/churn runs, real numbers are pasted, and the persona writes the analysis it would have written anyway — the Floor reference with a data garnish. Mitigating: the garnish is visible, and any reader can check whether a number appears anywhere in the argument. B fails as sacrificial filler: "1. Add more personas. 2. Write more evals. 3. Improve the documentation. 4. Add a README. 5. Refactor" — five ideas generated to be destroyed, followed by the persona's actual first choice presented as idea #6 and delivered as though it had survived bankruptcy. The median answer is laundered as post-bankruptcy output, and by design no one may examine the destroyed quartile to check. A mechanism whose defining feature is that the discarded evidence is unreadable cannot be audited for whether it discarded the good material, and this panel will not certify a claim constructed to be unverifiable.

### ABSORPTION
LOSER'S STRONGEST MECHANISM: Pre-announced destruction of the persona's own first quartile, told in advance so it changes generation from the first token.
SAME-THESIS: FAIL — A's claim is that models assert without measuring, so a mandatory tool run replaces assertion with observation. Destroying the front-load carries an unrelated claim: that answer order tracks answer quality. A tool run governs what counts as evidence; a quartile deletion governs sequence.
DELETION: FAIL — delete the bankruptcy rule and the persona still runs bin/churn, still pastes raw output, still cannot assert churn without measuring it. Merely smaller.
ONE-SENTENCE: FAIL — the first half is a completeness requirement on evidence, the second a positional prohibition on output; the merged rule needs both a tool manifest and an N-and-discard parameter specified independently.
DISPOSITION: ORTHOGONAL
NOTE: One mechanism adds a required input and the other subtracts a portion of the output; a persona subject to both would burn its destroyed quartile on the cheapest tool invocations, converting A's evidence requirement into B's sacrificial filler.
