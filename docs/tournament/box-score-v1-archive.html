The 99th
Idea Bracket

Thirty-two mechanisms for forcing randomness — and therefore creativity — into a model that has been trained toward consistency. Seeded into four regions, run head to head. The more creative idea wins and absorbs the best part of the idea it beat, so every survivor is a chimera and the Final Four are four rival theories rather than four surviving tricks.

A creative workshop asks a room for 100 ways to protect a home. The first ten are a fence, a dog, a camera. The last ten are a moat and a fleet of UFOs that abduct intruders. The value was never the moat. It is that reaching idea #99 requires a different generative process than reaching idea #3 — and temp-agency currently stops at about #12.

how a game is decided

The 99th-Idea Rubric

Five axes, ten points each. The axes reward distance from the median output, not implementability — a cheap mechanism that pushes the model somewhere it would never go beats an expensive one that produces a better version of where it already goes.

AxisThe question it asksWhat a low score looks like
DistanceHow far from the median AI answer does this push the output?The default answer, better organized
MechanismDoes something actually execute, or is this exhortation?A paragraph asking the model to try harder
IrreducibilityCould the base model already do this if simply asked nicely?Yes — "be more creative" gets 80% of it
CompoundingDoes it get weirder with use, or does the novelty wear off?Identical on the tenth use as the first
Generative failureWhen it breaks, does it produce a different kind of insight — or noise?Noise, or nothing at all

Irreducibility is load-bearing. It is this repo's own doctrine — encoded preference over capability uplift — turned on mechanisms instead of personas. A mechanism the model can simulate when asked politely is not a mechanism.

the draw

Four regions, four theories of creativity

Regions are thematic rather than arbitrary, so a regional champion represents a coherent philosophy and the Final Four is a genuine argument. Each region names the enemy it thinks is responsible for homogeneous output.

Entropy

Inject genuine outside material or genuine randomness. If the model cannot reach it from where it is, bring it in from elsewhere.

EnemyThe model's simulated randomness, which is just retrieval wearing a costume.

Constraint

Take away the thing the model always reaches for. Creativity as subtraction, not addition.

EnemyThe signature move — always available, therefore always taken.

Apparatus

Make the lens execute instead of asking it to. Code, weights, tools, topology — a prosthetic rather than a costume.

EnemyMarkdown that requests a behavior and then hopes.

Memory

Make the repo remember, so it cannot repeat itself. History as a shrinking space of permitted answers.

EnemyThe fresh context window, which lets a persona make the same excellent point forever.

the field of 32

Entrants

Owner entries are marked in brass; the four flagged as "vague enough to split" were split. The rest were generated to fill the field. No two entrants may share a primary mechanism — several attack the same target, but prohibition, entropy, execution and memory are four different means.

box score

Every matchup

Twenty-eight games. Each card shows where the game was won on the five axes, the verdict, and what the winner took with it. Click any lineage code to trace an original entrant through the bracket and see what absorbed it.

tournament halted — owner review

The Final Four

The bracket stops here by design. Each survivor is now a composite of six to eight original entrants, and which one advances determines the repo's next architecture — that is a decision, not a scoring exercise. Semifinals are not run without a call on these four.
