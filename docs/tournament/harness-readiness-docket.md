## Ruling 25 — A6 distinctness

**Recommendation: retain A6 as distinct and authorize a bounded recipe implementation.**
A5 removes information or resources from the environment while leaving the performer
intact. A6 keeps the task available and deliberately misapplies the performer's method:
wrong phase order, signature-technique overuse, and principle misidentification.

Applied to the existing three-test absorption standard:

- Same thesis: “less information” and “misapplied expertise” are different causes of
  output change. Treating both as generic degradation erases the operative distinction.
- Deletion: removing the understudy recipe leaves A5's withheld-input mechanism
  intact. No evidence yet shows A5 becomes worse without A6.
- One sentence: a combined implementation would need both input deprivation and
  deliberate method errors. That imports a second mechanism rather than strengthening
  the current A5 operation.

The present evidence therefore favors separate evaluation over absorption. This is
not proof that A6 will be creatively useful. If retained, freeze the recipe, preserve
an understudy response alongside the bounded expert response, and check that synthesis
does not silently repair the errors. Do not replace the recipe with a weaker model.
No A6 code or official admission policy has been introduced without that decision.
